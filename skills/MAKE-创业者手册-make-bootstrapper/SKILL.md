# MAKE: Bootstrapper's Handbook — 单人创业操作手册

> 你不需要融资、不需要团队、不需要办公室。一个人 + 互联网 = 一家公司。

Pieter Levels 是 Nomad List、Remote OK、PhotoAI 的创始人——全是单人打造，年入百万美元。

---

## 单人创业四步法

### 1. 验证（Validate）

在写代码之前先验证。做一个简单的落地页，描述你的产品→ 放一个邮箱收集框 → 投 $50 广告 → 看有没有人注册。100 人注册 = 有需求。0 人 = 换方向。

### 2. 构建（Build）

只做最关键的功能。第一版必须一周内发布。不是「在做了」，是「上线了，能用」。完美是发布的敌人。

### 3. 发布（Launch）

在 Product Hunt、Hacker News、Reddit、Twitter 发布。写一篇诚实的博客讲述你的构建过程。做得好不如讲得好。

### 4. 自动化（Automate）

把一切能自动化的都自动化：支付、客服、营销邮件。你的目标不是工作更多，是工作更少但收入不变。

---

## Pieter Levels 的核心原则

- **不融资**：融资 = 给自己找了个老板
- **不招人**：招人 = 管理时间 > 创造时间
- **做多个小产品**：一个死了不影响其他的
- **公开构建**：把过程发在 Twitter 上 → 免费营销 + 早期用户
- **数据库 + 界面 = 生意**：最简单的产品就是一个数据库加一个好看的前端

---

## 一句话总结

**你不需要等任何人批准。今天做一个落地页，明天看有没有人注册。那就是你的第一个产品。**
