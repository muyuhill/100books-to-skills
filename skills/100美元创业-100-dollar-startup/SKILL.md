# The $100 Startup — 极低成本微型创业框架

> 你不用 MBA、不用风投、不用详尽计划。你只需要三样东西：一个产品或服务、一群愿意付钱的人、一个收钱的方式。

这本书研究了 1500+ 个体创业者，提炼出通用规律。核心发现：**最成功的微型创业起步平均只需 $100。**

---

## 框架一：Convergence 收敛模型

**这是全书最核心的框架。** 找到你擅长/热爱的事和别人愿意付钱的事之间的交集。

```
       你的激情/技能        别人愿意付钱的
       ┌─────────┐         ┌─────────┐
       │ 爱吃披萨 │         │ 需要减肥 │
       │ 会弹吉他 │         │ 想学吉他 │
       │ 会写代码 │   ──→   │ 要建网站 │
       └────┬────┘         └────┬────┘
            │                   │
            └──── 交集 = 生意 ──┘
```

**注意**：不是你喜欢的都能卖。我爱吃披萨但没人付钱让我吃。关键是找到 **我喜欢且有人需要的那个点**。

### 收敛公式

```
激情或技能 + 实用性 = 成功
```

即：Passion or Skill + Usefulness = Success

### 检查清单

1. 这个事我喜欢做（或者至少不排斥）吗？
2. 有人愿意为此付钱吗？
3. 这个交集够大，能支撑起一份收入吗？

## 框架二：Skill Transformation 技能转化

> 你不是只擅长一件事。把多项普通技能组合起来，就是独特价值。

**Scott Adams（呆伯特漫画家）自评**：
- 绘画水平：一般
- 写作水平：还行
- 幽默感：普通
- 商业经验：有点

每一项单独都不突出，但**四项凑在一个人身上，就是独一无二**。

### 技能转化三步

1. **列出你的所有技能**（不只是工作技能——爱好、生活技能也算）
2. **圈出 2-3 个能组合的技能**（教师 = 教学 + 沟通 + 组织 + 共情）
3. **问自己**：这个组合能解决谁的问题？

**案例**：钢琴老师 Brandon 发现自己最烦的是管理学生排课收费。他会一点编程 → 写了个排课软件 → 其他老师也要 → 月入 $30,000。

## 框架三：微型创业三要素

> 任何生意，拆到最简就是三个东西：

```
┌──────────────────────────────────┐
│  ① 产品/服务  →  你卖什么         │
│  ② 客户       →  谁愿意付钱       │
│  ③ 收钱方式   →  怎么完成交易     │
└──────────────────────────────────┘
```

缺一不可。有客户没产品 = 有需求没供给。有产品没客户 = 自嗨。都有但没法收钱 = 白干。

---

## 框架四：一页商业计划

> 如果商业计划超过一页纸，说明你想太多了。

不需要 50 页的 BP。只需要回答：

1. **价值主张**：你帮谁解决什么问题？
2. **客户来源**：第一批客户从哪来？
3. **收入模型**：怎么定价？卖什么？（产品/服务/订阅/组合）
4. **启动成本**：最少花多少钱能跑起来？
5. **第一步行动**：今天就能做的一件事是什么？

---

## 框架五：不可抗拒的 Offer

> 不是你卖什么，是你**怎么卖**。

### 三步打造 Killer Offer

1. **快速给价值**：客户花钱后立刻得到什么？（不要让他们等）
2. **消除风险**：退款保证 / 试用期 / 不满意退钱
3. **超出预期**：加赠品 / 额外服务 / 惊喜（客户觉得"赚到了"就帮你传播）

### 定价铁律

- 不要按成本定价，按**价值**定价
- 如果没人嫌贵，说明你定价太低了
- 涨价是最好的增长策略——多出来的利润可以用来服务更少的客户

## 框架六：一页推广计划

> 广告是付费的。Hustling（推广）是免费的。而且 Hustling 效果更好。

Guillebeau 做了测试：$10,000 广告 vs 10 小时免费推广。结果：

| | 广告 | Hustling |
|---|:---:|:---:|
| 成本 | $10,000 | 10 小时 |
| 新客户 | 78 | **84** |
| 客户价值 | $7,020 | **$7,560** |

### 一页推广计划（One-Page Promotion Plan）

| 频率 | 行动 |
|------|------|
| **每日** | 社交平台发 1-3 条有价值的内容，回复评论和私信 |
| **每周** | 找同行互推 / 联合推广；定期联系潜在客户 |
| **每月** | 回访老客户：「还有什么我能帮你的？」 |
| **偶尔** | 做业务审计（哪里还有没抓住的机会？） |

## 框架七：Launch 发布策略

> 不需要完美才发布。在「够好了」的时候就发。

### 发布前检查

- [ ] 有人明确说过「我需要这个」吗？
- [ ] 定价有人愿意付吗？（哪怕只有一个人说愿意）
- [ ] 客户怎么付钱？（PayPal？微信？）
- [ ] 发布日做什么？（发帖？发邮件？告诉朋友？）

### 发布后

- 前 72 小时最重要——集中回复、集中转发
- 收集前 10 个客户反馈 → 立刻改进
- 问每个客户：「你最喜欢哪一点？哪里还可以更好？」

---

## 框架八：失败了怎么办

> 大多数微型创业不会「死」，只会「休眠」。你的投入是 $100，不是 $100,000。

### 如果产品卖不动

1. 回到 Convergence 模型：交集对不对？
2. 调整 Offer：定价太高还是价值不够？
3. 换个推广渠道：是不是蹲错地方了？
4. 很多时候，需要的是**微调**而不是**重来**

### Guillebeau 的金句

> "在你赚到第一块钱之前，你只是一个有爱好的人。"

## 一句话总结

**找到你擅长且别人需要的交集 → 用一页纸规划 → 快速发布 → 免费推广 → 根据反馈调整。启动成本不到 100 美元。**
