# 《非暴力沟通》— 四步让你的话被真正听见

> 当语言从「你让我生气」变成「我感到……因为我需要……」，冲突就从对抗变成了连接。

马歇尔·卢森堡的核心主张：**暴力不仅存在于肢体冲突，更存在于日常语言。** 指责、比较、评判、强求——这些「疏离生命的沟通」每天都在切断人与人之间的连接。非暴力沟通不是让你「说话好听」，而是让你说话**真实且不伤人**——用四步把指责变成请求，把对抗变成合作。

---

## OFNR 四步法

```
观察（Observation）→ 感受（Feeling）→ 需要（Need）→ 请求（Request）
      ↑                                                    │
      └── 每一步都为下一步提供基础，缺一不可 ────────────────┘
```

| 步骤 | 核心问题 | 错误示范 | 正确示范 |
|------|---------|---------|---------|
| **观察** | 我看到了什么？（不加评判） | 「你总是迟到」 | 「这周三次会议你都在9:05之后到的」 |
| **感受** | 我现在的感受是什么？（不包藏指责） | 「我觉得你不在乎我」 | 「我感到失落和担心」 |
| **需要** | 我背后的需要是什么？（真实需求） | 「我需要你更负责任」 | 「我需要尊重和效率」 |
| **请求** | 你愿意做什么？（具体可操作） | 「你能不能靠谱一点？」 | 「下次你愿意提前5分钟到吗？」 |

---

## 第一步：观察 — 说事实，不说故事

> 不带评论的观察，是人类智力的最高形式。——克里希那穆提

区分观察与评论，是非暴力沟通最难的第一步。

### 观察 vs 评论

| 评论（Evaluation） | 观察（Observation） |
|-------------------|---------------------|
| 你太懒了 | 你这周三次说要去健身，但都没去 |
| 他工作不认真 | 他的报告连续两次有数据错误 |
| 你总是忽视我 | 我说话的时候，你这三次都在看手机 |
| 你从来不守信用 | 你答应周三交，今天周五还没给我 |
| 他是个差劲的队友 | 他在项目会议上一共发言了两次 |

**关键词警报**：当你使用「总是」「从不」「经常」「很少」这些词时——停下来，问自己：这是事实，还是我的放大？

### 实践检查清单

- [ ] 去掉副词：「总是」「从来」「每次」「从不」
- [ ] 去掉标签：「懒」「笨」「不负责」「自私」
- [ ] 像摄像头一样描述：谁在什么时间什么地点做了什么？
- [ ] 自问：如果对方和我一起看监控录像，我们看到的是一样的东西吗？

## 第二步：感受 — 说情绪，不说想法

> 在非暴力沟通中，感受没有对错。感受只是信使。

很多人以为在说感受，其实在说想法——而想法里往往藏着指责。

### 感受 vs 想法

| 想法（包藏指责） | 感受（单纯的情绪） |
|-----------------|-------------------|
| 我觉得你不在乎我 | 我感到孤独、伤心 |
| 我感觉被攻击了 | 我感到紧张、害怕 |
| 我觉得这不公平 | 我感到愤怒和委屈 |
| 你让我很生气 | 我很生气 |
| 我感觉被抛弃了 | 我感到恐惧和孤单 |

**核心区别**：想法以「你」开头或暗示对方的错，感受只说「我」的情绪状态。

> 「你让我生气」→ 把情绪的遥控器交给了对方。  
> 「我感到愤怒，因为我需要尊重」→ 收回遥控器，为自己的情绪负责。

### 感受词汇表

**当需要得到满足时**：满足、欣慰、兴奋、放松、感激、温暖、安全、信任、活力、喜悦、好奇、自豪、平静、感动、释然

**当需要没有得到满足时**：愤怒、失望、焦虑、孤独、委屈、紧张、疲惫、无助、沮丧、烦躁、嫉妒、伤心、内疚、麻木、恐惧、不安

---

## 第三步：需要 — 说需求，不说策略

> 每个感受背后，都有一个未被满足的需要。暴力源于对需要的看不到。

这是 OFNR 中最容易被跳过但最关键的一步。大部分冲突卡住，不是因为需求不可调和——而是因为**需求根本没被说出口**。人们争论的是「策略」（你该怎么做），而不是「需要」（我到底要什么）。

### 策略 vs 需要

| 策略（你怎么做） | 需要（我要什么） |
|----------------|----------------|
| 你每天要给我发消息 | 我需要连接和安全感 |
| 你必须周末陪我 | 我需要陪伴和亲密 |
| 你应该把家务做了 | 我需要秩序和分担 |
| 你不要再批评我了 | 我需要尊重和被看见 |

**一个需要，可以有多种策略满足**。当你卡在唯一的策略上寸步不让，战争就开始了。当你退回到需要层面讨论，合作就有了空间。

### 人类的基本需要（非暴力沟通经典清单）

- **自主**：选择梦想/目标/价值观的自由
- **连接**：接纳、欣赏、亲密、爱、尊重、理解、支持、信任、温暖、被看见
- **意义**：贡献、创造、成长、学习、清晰、自我表达
- **身体的福祉**：休息、食物、安全、运动、健康
- **和平**：秩序、和谐、平静、空间
- **玩耍**：乐趣、欢笑、放松

## 第四步：请求 — 说行动，不说要求

> 请求和要求的区别不在于你说得多客气，而在于——当对方说不的时候，会怎样。

### 请求 vs 要求

| 要求（Demand） | 请求（Request） |
|---------------|----------------|
| 对方说「不」后你惩罚/指责/冷暴力 | 对方说「不」后你继续倾听他的感受和需要 |
| 「你必须……」「你应该……」 | 「你愿意……吗？」「……可以吗？」|
| 目标是控制对方的行为 | 目标是建立基于诚实和同理心的连接 |

### 好请求的三个条件

1. **具体可操作** — 对方能清楚知道做什么
   - ✘ 「多陪陪我」
   - ✔ 「每周三晚上一起散步30分钟，可以吗？」

2. **正向语言** — 说你要什么，不要说你不要什么
   - ✘ 「别总是打断我」
   - ✔ 「让我先把话说完，然后你来补充，可以吗？」

3. **当下可行** — 请求的是一个动作，不是一个状态
   - ✘ 「以后更尊重我」
   - ✔ 「下次做决定之前先问我一句，可以吗？」

### 请求后的确认

> 请求需要确认对方是否真的听懂了——而不是以为懂了。

- 「我刚才说的清楚吗？你听到的是什么呢？」
- 「你能重复一下你理解我要表达的吗？」

## 完整的 OFNR 模板

### 对自己说（自我连接）

```
当我看到/听到______（观察），
我感到______（感受），
因为我需要______（需要），
你愿意______（请求）吗？
```

### 对他人说（诚实表达）

```
你愿意听我说一下刚才发生了什么吗？

情况是这样的：______（观察——不评判的事实），
我现在感到______（感受——不加指责的情绪），
因为对我来讲，______（需要——背后的真实需求）很重要。
所以我想请求你：______（请求——具体的、可操作的下一步），可以吗？
```

### 对他人说（同理倾听）

```
当你看到/听到______（猜测对方的观察），
你是不是感到______（猜测对方的感受），
因为你需要______（猜测对方的需要）？
是这样吗？
```

## 同理心倾听 — 只听感受和需要

> 不要只是「听对方的话」，去听「他没有说出口的感受和需要」。

这是非暴力沟通最被低估的技能。当对方在愤怒、抱怨、指责你的时候——你可能本能地想辩解、解释、反驳、给建议。但卢森堡说：**这时候唯一有效的回应，是同理心倾听。** 把对方话里的「你」翻译成「我」，去找背后的感受和需要。

### 四种阻断连接的回应 vs 同理心回应

| 对方说 | 阻断回应 | 同理心回应 |
|--------|---------|-----------|
| 「你从来不听我说话！」 | 解释：「我刚刚听了啊」 | 「你是不是感到沮丧，因为你希望被听见？」 |
| 「这工作太烦了」 | 建议：「你换个角度想嘛」 | 「你是不是感到疲惫，因为你需要一些意义感？」 |
| 「你怎么又迟到了」 | 反击：「你上次也迟到了」 | 「你是不是有点生气，因为你需要尊重约定的时间？」 |
| 「我不想跟你说话了」 | 追问：「你什么意思啊」 | 「你现在的感受可能是受伤或者生气，因为你需要一些空间，对吗？」 |

### 同理心倾听的原则

1. **不给建议** — 除非对方明确请求
2. **不评判** — 「你不该这么想」是暴力
3. **不比较** — 「你那算什么，我才惨」
4. **不安慰太快** — 「别难过了」在否定对方的感受
5. **不解释/不辩护** — 先倾听，后表达
6. **不纠正** — 「事实不是这样的」

### 倾听时的句式

- 「你是不是感到______，因为你需要______？」
- 「听起来你______（感受），是这样吗？」
- 「所以对你来说，______（需要）非常重要，对吗？」
- （对方说了很多但你抓不住）「能帮我理解一下，你现在的感受和需要是什么吗？」

## 自我连接 — 对自己也非暴力

> 如果你对自己充满评判和指责，你无法对别人真正非暴力。

大多数人对自己比对外人更暴力：「我真蠢」「我又搞砸了」「我不够好」。这些内在对话，会以微妙的方式转化为对外的攻击。

### NVC 版的自我对话

| 旧台词 | NVC 翻译 |
|--------|---------|
| 我又失败了 | 我做了这件事，结果不如预期。我感到失望，因为我需要成长。我学到的是______ |
| 我不够好 | 我感到不安，因为我需要自我认同。我能做什么来满足这个需要？ |
| 我不该生气 | 我此刻感到愤怒，这个愤怒在告诉我，我有一个需要没有被满足。我倾听我的愤怒 |
| 他凭什么这样对我 | 他的行为触发了我对______的需要未满足。我选择为自己的感受负责 |

### 从「应该」到「选择」

> 「我应该……」背后是义务和内疚；「我选择……」背后是自由和需要。

- ✘ 「我应该去健身」→ 「我选择去健身，因为我需要健康和活力」
- ✘ 「我不该发火」→ 「我选择用同理心重新理解刚才发生了什么」
- ✘ 「我必须加班」→ 「我选择加班，因为我需要在截止日期前完成承诺」

## 化解冲突的五步法

> 冲突的真正解决，不是一方赢了——而是双方的需要都被听到、都被认真对待。

卢森堡在《非暴力沟通》中给出了冲突调解的具体流程：

### 1. 建立连接（在碰内容之前）

在解决任何「事情」之前，先确认对方愿不愿意用同理心的方式谈这件事。

- 「你愿意用几分钟时间，我们先听清楚彼此的需要吗？」
- 「我不是来争对错的——我是来找到办法让我们都能好过的。」

如果对方不在同理心的状态，**先倾听**——不要急着推进解决问题。

### 2. 各自表达观察 + 感受 + 需要

不要上来就提方案。每个人只说：

- 我看到了什么（观察）
- 我现在什么感受（感受）
- 我需要什么（需要）

**这一步禁止提策略。** 只讲需要。

### 3. 确认双方都听懂了对方的需要

这是最关键但最容易被跳过的一步：

- 「我听到你的需要是______，对吗？」
- 「你觉得我理解你的需要了吗？」
- 「你能告诉我，你理解我的需要是什么吗？」

在双方都确认「是的，你懂我了」之前，**不进入下一步**。

### 4. 共同头脑风暴策略

现在终于可以提方案了。但关键心态：没有人的策略是唯一的。目标是找到能满足**双方需要**的策略，不是说服对方接受你的策略。

- 「有哪些办法可以同时满足你的需要（尊重）和我的需要（效率）？」
- 「我们写下来 5 种可能性，先不评价好不好——」

### 5. 选择一个尝试的策略 + 约定回顾

- 不追求完美方案，追求「下一个可试的实验」
- 明确时间：「先试一周，下周三我们再看这个方法行不行」
- 如果试了不行——回到需要层面重新来，而不是指责「你又搞砸了」

## 沟通中的「四不原则」

卢森堡把日常沟通中最大的四个雷总结为：

| 不要做 | 为什么 | 替代方案 |
|--------|--------|---------|
| **不评判** | 评判引发防御——防御关闭连接 | 说观察：不带标签地描述事实 |
| **不比较** | 比较是评判的一种，阻断同理心 | 关注当下这个人的真实状态 |
| **不推卸责任** | 「我不得不……」否认了自己的选择权 | 「我选择……因为我需要……」 |
| **不强求** | 要求制造恐惧和反抗，请求创造尊重和合作 | 用问句，给对方说「不」的空间 |

## 快速上手：5 步实践指南

> 不要试图一次完美。今天只练一步。

### 第一天：开始觉察你在说什么

观察你今天的对话。你说了几句「你总是……」或「你从来不……」？不用改，只是**看见**。

### 第二天：把一句评论换成观察

挑一次对话，把你几乎要脱口而出的评论停住，换成纯粹的事实描述。

- 想说「你这人怎么这么不靠谱」→ 改成「你答应今天交，现在快下班了我还没收到」

### 第三天：说出一个真实的感受

不是「我感觉你不尊重我」，而是「我感到有点受伤和委屈」。找感受词汇表里的词，说出来。

### 第四天：问自己「我到底需要什么」

在你感到烦躁、愤怒、沮丧的那一刻，停下来问一句：**我真正的需要是什么？** 把它写在纸上。

### 第五天：把一句要求改成请求

挑一个你想让别人做的事，从「你应该……」改成「你愿意……吗？」然后——**认真听对方的回答**，不管他说的是 yes 还是 no。

---

## 一句话总结

> **非暴力沟通的本质不是改变说话方式，而是改变注意力的方向——从「谁对谁错」转向「你我各自有什么感受、需要什么」。** 当需要被看见，问题就解决了一半。
