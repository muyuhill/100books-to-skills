# 《疯传》— 六大原则，让你的想法自己传播

乔纳·伯杰 (Jonah Berger) 的《疯传：让你的产品、思想、行为像病毒一样入侵》揭示了为什么有些内容会像野火一样传播，而大多数则无人问津。核心框架是 **STEPPS 六大原则**——帮你系统化地设计具有传播力的内容。

---

## 框架总览：STEPPS

```
S — Social Currency  （社交货币）
T — Triggers         （触发物）
E — Emotion          （情绪）
P — Public           （公共可见性）
P — Practical Value  （实用价值）
S — Stories          （故事）
```

> 不需要六条全满足——通常满足 3-4 条就足以产生病毒传播效应。

---

## S — Social Currency · 社交货币

**核心洞见**：人们分享能让自己看起来更好的东西。分享是一种"自我呈现"行为——我们分享什么，就是在向世界宣告我们是谁。

### 三种社交货币策略

| 策略 | 原理 | 典型案例 |
|------|------|----------|
| **内部身份** | 让用户感觉自己是"圈内人"，知道别人不知道的事 | 请勿外传的私密链接、限量邀请码、Beta 测试资格 |
| **游戏机制** | 通过排行榜、徽章、等级让用户获得可炫耀的成就 | 航空公司会员等级、星巴克金卡、微信运动步数排名 |
| **制造稀缺与 exclusivity** | 限量版、限时抢购——稀缺的东西让人更想拥有也更想炫耀 | Supreme 限量发售、拼多多"还剩最后3件" |

### 实战清单

- [ ] 你的内容/产品能不能让分享者看起来更聪明、更酷、更有见识？
- [ ] 有没有"内部人士才知道"的信息可以透露？
- [ ] 能不能加入可量化的成就系统（数字、等级、徽章）？
- [ ] 有没有稀缺性或 exclusivity 可以制造？（时间、数量、资格）

### 反例警示

- 让人分享后显得"low"或"掉价"的内容——社交货币 < 0，传播力归零
- 虚假的稀缺一旦被识破，信任崩塌的速度比传播还快

## T — Triggers · 触发物

**核心洞见**：人们想到什么就会谈论什么。激活频率比兴趣更重要——一个"无聊"但被高频触发的品牌，比一个"有趣"但低频触发的品牌获得更多口碑。

### 触发物设计三要素

1. **高频**：你的触发物在人们日常生活中出现的频率有多高？
2. **强关联**：看到触发物，想到你的产品/内容的链接有多强？
3. **场景匹配**：触发物是否出现在目标受众的正确场景中？

### 经典案例

- **KitKat × 咖啡**：KitKat 的广告策略是"休息一下，来根 KitKat"，将品牌与咖啡这个高频触发物绑定。咖啡是每天的高频行为 → KitKat 被高频联想。
- **丽贝卡·布莱克的《Friday》**：歌本身很差，但每到周五就被大量分享和提及——"周五"这个高频日历节点成了完美的触发物。
- **"啤酒"比"红酒"更常被提及**：不是因为更好喝，而是因为触发场景更多、更日常。

### 实战清单

- [ ] 你的内容/产品绑定到了什么高频的日常触发物？
- [ ] 受众在什么时间、什么场景下最可能想起你？
- [ ] 能不能把触发物植入广告语中？（如"困了累了喝红牛"）
- [ ] 有没有"日期型触发"可以利用？（周五、发薪日、节日、开学季）

### 注意事项

- 触发物要具体，不要抽象——"午餐"比"幸福感"更好触发
- 在目标行为发生前一刻出现最有效——"渴了"比"喝完"更有力

## E — Emotion · 情绪

**核心洞见**：不是所有情绪都驱动分享。关键在于**唤醒水平 (Arousal)**——高唤醒情绪驱动行动，低唤醒情绪让人沉默。

### 情绪唤醒度分类

| 高唤醒（驱动分享 🚀） | 低唤醒（抑制分享 🛑） |
|---------------------------|----------------------------|
| 敬畏 (Awe)                | 满足 (Contentment)         |
| 愤怒 (Anger)              | 悲伤 (Sadness)             |
| 兴奋 (Excitement)         | 平静 (Calm)                |
| 焦虑 (Anxiety)            | 放松 (Relaxation)          |
| 幽默 (Humor / 开怀大笑)   | 温和愉悦 (Mild pleasure)   |
| 惊奇 (Surprise)           |                            |

### 核心要点

- **感动落泪 ≠ 传播力强**：悲伤是低唤醒情绪，让人内省而非行动。
- **愤怒是传播力最强的情绪之一**：因为它同时具有高唤醒 + 道德义愤的驱动。
- **科学实验**：让被试跑步（生理唤醒）后，他们分享信息的概率显著提升——**身体唤醒也会促进信息传播**。

### 实战清单

- [ ] 你的内容激发的是高唤醒还是低唤醒情绪？
- [ ] 能不能加入敬畏元素？（震撼数据、宏大叙事、视觉奇观）
- [ ] 有没有让人"又气又笑"的矛盾情绪？（混合高唤醒 = 双倍传播力）
- [ ] 幽默够不够"硬"？——让人嘴角微扬 ≠ 让人大笑分享
- [ ] 读者读完会不会有"生理反应"？（起鸡皮疙瘩、心跳加快、拍桌子）

### 情绪设计公式

```
传播力 = 唤醒水平 × 情绪强度
```

- 高唤醒 × 高强度 = 疯传级别（如感人+震撼的公益广告）
- 高唤醒 × 低强度 = 可传播（如有点搞笑的表情包）
- 低唤醒 × 任何强度 = 难以传播（如温馨但平淡的日常记录）

## P — Public · 公共可见性

**核心洞见**：人们会模仿他们能看到的行为。"看得见的才会被模仿，看不见的等于不存在。"

### 三大子原则

#### 1. 社会证明 (Social Proof)
人们通过观察他人行为来判断什么是正确的。排队越长的餐厅，人们越想去。

#### 2. 行为可见性
让原本私密的行为公开化，就能驱动更多人模仿。

#### 3. 自我广告 (Self-Advertising)
设计产品时就让"使用行为"自动成为广告。

### 经典案例

| 案例 | 机制 |
|------|------|
| **Apple 白色耳机** | 在黑色耳机时代，白色耳机让每一根线都是行走的广告牌 |
| **Hotmail 邮件签名** | "PS: Get your free email at Hotmail"——每封邮件都是传播载体 |
| **Movember 胡子运动** | 11月蓄胡子为男性健康募捐——脸上的胡子就是活广告 |
| **Livestrong 黄色手环** | 一个简单的配饰让癌症公益"穿"在每个人手上 |
| **共享单车** | 满街的橙色/黄色/蓝色单车本身就是最强的品牌曝光 |

### 实战清单

- [ ] 用户使用你的产品时，别人能不能"看到"他们在用？
- [ ] 能不能给用户一个"行为残留"？（贴纸、徽章、专属头像框、分享卡片）
- [ ] 有没有类似"邮件签名"的低成本自我广告机制？
- [ ] 你的私密行为能不能被"可视化"？（Spotify 年度总结让听歌这个私密行为变成社交内容）

### 反例

- 请勿酒驾广告的悖论：广告本身让"很多人都在酒驾"变得可见 → 反而让酒驾看起来更"正常"
- **解决方案**：让正确行为（不酒驾、朋友互相阻止）变得可见，而非强调坏行为的普遍性

## P — Practical Value · 实用价值

**核心洞见**：人们分享有用的信息，因为这让他们成为"帮助者"，同时也在积累自己的社交货币。实用信息是"利他+利己"的双赢分享。

### 实用价值的设计杠杆

#### 1. 信息打包 (Framing)
同样的价值，不同的表达方式，传播力天差地别：

| 表达方式 | 效果 |
|----------|------|
| "省 20 元" vs "打 8 折" | 原价低时用百分比（更震撼），原价高时用绝对值（更直观）|
| "每天只需 3 块钱" | 把大数字拆成小数字——降低心理负担 |
| "比同类产品快 3 倍" | 用对比让抽象优势变得具体 |
| "100 个人里有 97 个推荐" | 用具体数字替代"绝大多数" |

#### 2. 100 法则
- 原价 < 100 元 → 用**百分比折扣** ("打 7 折！")
- 原价 > 100 元 → 用**绝对金额** ("直降 500 元！")

#### 3. 限制性建议
- 不要给一长串建议——**选一条最强的，用最具体的方式说**。
- "5 个省钱技巧"不如"一个节省 30% 燃气费的方法"。

#### 4. 反直觉知识
- 信息越反直觉、越打破常识，传播力越强。
- 例："你每天用的牙膏其实是化妆品，不是药品。" ← 颠覆认知

### 实战清单

- [ ] 你的内容有没有"看完就能用"的具体价值？
- [ ] 核心信息有没有用最好的方式"打包"？（百分比 vs 绝对值、对比法、拆分法）
- [ ] 有没有反常识的"冷知识"可以嵌入？
- [ ] 能不能做成清单、教程、模板等"可收藏"的格式？
- [ ] 分享者分享了它，接收者会觉得分享者"帮了我一个忙"吗？

## S — Stories · 故事

**核心洞见**：信息像特洛伊木马——直接讲道理没人听，但裹在故事里就能"偷渡"进人们心里。关键是：**故事与品牌/信息不可分割**——如果故事精彩但没人记得你的品牌，那只是娱乐，不是营销。

### 好故事的三个层次

1. **表面层（情节）**：发生了什么——吸引注意力的钩子
2. **中层（情感）**：角色经历了什么情感变化——让人代入和共鸣
3. **底层（信息）**：品牌/产品/价值观——故事的"payload"，必须与叙事融为一体

### 不可分割性测试

讲完故事后问三个问题：
- 如果去掉你的品牌/产品，这个故事还能完整讲下去吗？
- 听者复述这个故事时，会不会自然提到你的品牌/产品？
- 故事的核心冲突或转折点，是不是由你的产品/价值观驱动的？

> 如果答案都是"否"——你的品牌只是故事里的一个广告植入，不是故事本身。

### 经典案例

| 案例 | 不可分割性 |
|------|------------|
| **Dove 真美素描** | 故事核心就是 Dove 的价值观（女性自我认知），去掉品牌故事就不存在 |
| **特斯拉 Roadster 上天** | 故事荒诞到任何人复述都绕不开特斯拉 |
| **海底捞"极致服务"段子** | 每个故事（送西瓜、帮忙带孩子、做指甲）都是海底捞服务价值的直接证明 |

### 实战清单

- [ ] 你的品牌/产品有没有一个"人们会主动讲给别人听"的故事？
- [ ] 这个故事去掉你的品牌还能完整存在吗？
- [ ] 故事中有没有"值得转述的细节"？（具体数字、意外转折、情感瞬间）
- [ ] 能不能把用户的使用体验包装成故事模板，让用户自己成为"讲故事的人"？

### 好故事结构模板

```
1. 挑战/冲突：一个具体的人遇到了什么问题
2. 转折/发现：用了你的产品/方法后发生了什么
3. 具体结果：用数字或细节让结果可信
4. 情感点睛：一个让人"啊"一声的瞬间
```

## STEPPS 综合应用：传播力自检矩阵

对你要传播的内容/产品/想法，逐项打分（1-5 分）：

| 原则 | 关键问题 | 得分 |
|------|----------|------|
| S 社交货币 | 分享它能让分享者看起来更好吗？ | /5 |
| T 触发物 | 有没有高频触发物让人经常想到它？ | /5 |
| E 情绪 | 它激发的是高唤醒情绪吗？ | /5 |
| P 公共性 | 使用/传播行为能被别人看到吗？ | /5 |
| P 实用价值 | 它包含值得分享的具体有用信息吗？ | /5 |
| S 故事 | 它有一个品牌不可分割的好故事吗？ | /5 |

- **总分 ≥ 22**：病毒传播级别，全力推广
- **总分 15-21**：有传播潜力，优化薄弱项
- **总分 < 15**：需要重新设计核心传播钩子

## 常见误区

| 误区 | 真相 |
|------|------|
| "质量好就会传播" | 质量是基础，但不是驱动力——没人因为"这牙刷质量不错"而发朋友圈 |
| "要覆盖全网" | 少数关键影响者比海量普通用户重要得多——找到你的传播节点 |
| "创意够好就行" | 没有触发物绑定，再好的创意也只火一次——设计"长效触发" |
| "悲情感人容易传播" | 悲伤抑制行动——让人转发的是愤怒和敬畏，不是眼泪 |
| "多给信息多分享" | 信息越聚焦越传播——一条清晰的实用价值胜过十条泛泛建议 |
| "线上才是传播" | 线下口碑占传播的绝大部分——设计"线下可谈论的钩子" |

---

## 快速上手：三步骤

1. **诊断**：用 STEPPS 矩阵给你当前的内容/产品打分，找到最弱的环节
2. **强化**：选 2-3 个最容易突破的原则，设计增强方案
3. **测试**：小范围投放，测量分享率、NPS、复述完整度，迭代优化

---

## 延伸思考

- **社交货币的阴暗面**：炫耀过头会引发反感——最好的社交货币让人"不自觉地"觉得分享者很棒，而不是"刻意显摆"
- **触发物的竞争**：所有竞品都在抢占同一批触发物——找到"被忽视的高频场景"是蓝海
- **情绪疲劳**：同一类情绪刺激会产生抗性——轮换情绪策略，敬畏→幽默→愤怒→兴奋
- **故事的保质期**：好故事会被反复讲述几十年——设计"常青故事"，而非一次性段子

---

> 💡 **一个终极问题贯穿全书**：当一个人和别人聊天时，为什么会主动提到你？——这就是 STEPPS 要帮你回答的。
