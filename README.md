# 📚 Book-to-Skill：让好书变成你的 AI 外脑

把商业/成长/搞钱类好书的**核心框架**提炼为 AI 可调用的 Skill。不是摘要，不是书评——是可执行的思维模块。

---

## 🤔 这有什么用？

读了一本好书 → 过两周忘了 80%。但如果把它的方法论变成一个 Skill：

> "帮我用《原子习惯》的四步法设计一个每天写作的系统"  
> "用 Hook-Story-Offer 审一下我这篇文章为什么没人看"  
> "参考 Dream 100 框架，帮我找目标用户在哪聚集"

AI 会按那本书的框架替你思考。**不是 AI 读了一本书，是那本书的作者附身 AI 帮你出主意。**

## 🚀 快速开始

### 如果你是 Hermes Agent 用户

```bash
# 下载 Skill
git clone https://github.com/muyuhill/100books-to-skills.git

# 复制到 Hermes 的 skills 目录
cp -r 100books-to-skills/skills/traffic-secrets ~/.hermes/skills/marketing/
```

### 如果你是 ChatGPT / Claude / 其他 Agent 用户

直接把任意 [SKILL.md](./skills/traffic-secrets/SKILL.md) 的内容粘贴到对话中，然后说：「以后遇到相关问题，请按这个框架分析。」

### 手动使用

每个 Skill 都是纯 Markdown，直接阅读就是一本浓缩版框架手册。

## 🤝 贡献

读过的好书里有一本想拆的？提取核心框架 → 按格式写一篇 SKILL.md → 提 PR。目标是让实用类好书都能变成可调用 Skill。

### 📖 什么书适合拆成 Skill？

| 适合 ✅ | 不适合 ❌ |
|---------|----------|
| 有明确框架/模型/步骤的 | 纯故事/小说/自传 |
| 方法论可复用、跨场景 | 纯理论无操作步骤 |
| 读完能立刻行动的 | 看完只增加谈资的 |
| 商业、效率、心理、营销类 | 纯历史、文学、哲学沉思 |

**典型适合的类别**：商业方法、效率系统、营销框架、决策模型、理财策略、沟通技巧、创意方法。
