# 📚 Book-to-Skill：让好书变成你的 AI 外脑 / Turn Books Into Your AI Brain

把商业/成长/搞钱类好书的**核心框架**提炼为 AI 可调用的 Skill。不是摘要，不是书评——是可执行的思维模块。

Extract the **core frameworks** from great business & self-improvement books into AI-callable Skills. Not summaries, not book reviews — executable thinking modules.

---

## 🤔 这有什么用？ / Why This?

读了一本好书 → 过两周忘了 80%。但如果把它的方法论变成一个 Skill：

Read a great book → forget 80% in two weeks. But turn its methodology into a Skill:

> "帮我用《原子习惯》的四步法设计一个每天写作的系统"  
> "Help me design a daily writing system using the Atomic Habits framework"  
> "用 Hook-Story-Offer 审一下我这篇文章为什么没人看"  
> "Review my article with the Hook-Story-Offer framework"

AI 会按那本书的框架替你思考。**不是 AI 读了一本书，是那本书的作者附身 AI 帮你出主意。**

AI will think using that book's framework. **It's not AI reading a book — it's the author helping AI think for you.**

## 🚀 快速开始 / Quick Start

### Hermes Agent 用户 / Hermes Agent Users

```bash
# Download all skills / 下载所有 Skill
git clone https://github.com/muyuhill/100books-to-skills.git

# Copy a skill to Hermes / 复制到 Hermes 的 skills 目录
cp -r 100books-to-skills/skills/流量秘密-traffic-secrets ~/.hermes/skills/marketing/
```

### ChatGPT / Claude / 其他 Agent 用户 / Other Agent Users

直接把任意 SKILL.md 的内容粘贴到对话中，然后说：「以后遇到相关问题，请按这个框架分析。」

Copy any SKILL.md content into your chat, then say: "From now on, analyze related problems using this framework."

### 手动使用 / Manual Reading

每个 Skill 都是纯 Markdown，直接阅读就是一本浓缩版框架手册。

Every Skill is pure Markdown. Read it directly as a condensed framework handbook.

### 📖 什么书适合拆成 Skill？ / What Books Work Best?

| 适合 ✅ Good Fit | 不适合 ❌ Bad Fit |
|---------|----------|
| 有明确框架/模型/步骤的 Clear frameworks/models/steps | 纯故事/小说/自传 Pure stories/novels |
| 方法论可复用、跨场景 Reusable, cross-scenario methods | 纯理论无操作步骤 Pure theory, no action steps |
| 读完能立刻行动的 Actionable immediately | 看完只增加谈资的 Just for conversation |
| 商业、效率、心理、营销类 Business, productivity, psychology, marketing | 纯历史、文学、哲学沉思 History, literature, philosophy |

**典型适合的类别 / Best categories**：商业方法 business methods、效率系统 productivity systems、营销框架 marketing frameworks、决策模型 decision models、理财策略 finance strategies、沟通技巧 communication skills、创意方法 creative methods。
